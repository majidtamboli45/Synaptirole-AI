
Settings Dashboard

[1] Notification Settings :- 


[1.1] Interview Recommendations

With the help of this Toggle Switch for Interview Recommendations, the user can choose whether they want to receive personalized interview recommendations.

ON: User receives recommendations for interview preparation and practice.
OFF: User will not receive interview recommendations.
Recommendations can include suggested topics, skills to improve, and suitable mock interviews.



[1.2] Interview Feedback

With the help of this Toggle Switch for Interview Feedback, the user can choose whether they want to receive a notification when their interview feedback/results are ready.

ON: User receives a notification when interview feedback is generated.
OFF: User will not receive feedback-ready notifications.



[1.3] Weekly Performance Summary

With the help of this Toggle Switch, the user can choose whether they want to receive a weekly summary of their interview performance.

ON: User receives a weekly performance report.
OFF: User will not receive weekly performance summary notifications.
The summary can include overall score, strengths, areas for improvement, and skill performance.

[2] Privacy Settings


[2.1] Profile Visibility

With the help of this Dropdown, the user can control who can view their profile information.

Possible options:
Only Me: Profile is visible only to the user.
Everyone: Profile can be viewed by other permitted users.



[2.2] Activity Tracking

With the help of this Toggle Switch, the user can control whether SynaptiRole AI can track their application and interview activity to provide better insights.

ON: The system tracks relevant activity to generate personalized insights and analytics.
OFF: Activity tracking is disabled.
This can affect the accuracy/personalization of performance insights.


[2.3] Data Usage

With the help of this Toggle Switch, the user can control whether their anonymous usage data can be used to improve the application.

ON: Anonymous usage data may be used for improving system performance and user experience.
OFF: Anonymous usage data will not be used for these improvement purposes.


[2.4] Download My Data

With the help of this Download/Arrow Button, the user can request or download a copy of their personal data and interview-related reports.

The downloaded data may include:

Profile information
Resume information
Interview history
Interview scores
Performance reports
Feedback
Skill analysis

[3] Appearance

[3.1] Theme

With the help of this Dropdown, the user can select their preferred application theme.

Possible options:

Light: Displays the application using a light theme.
Dark: Displays the application using a dark theme.
System Default: Automatically follows the user's device theme.



[3.2] Language

With the help of this Dropdown, the user can select the preferred language for the SynaptiRole AI interface.

The selected language changes the application's interface text.
This setting does not necessarily change the language used during an interview unless interview language is configured separately.
First Set Only By Default Language English



[3.3] Date Format

With the help of this Dropdown, the user can select how dates should be displayed throughout the application.

For example:
DD MMM YYYY → 22 Aug 2026
DD/MM/YYYY → 22/08/2026
MM/DD/YYYY → 08/22/2026
YYYY-MM-DD → 2026-08-22
The selected format should be applied consistently across interviews, reports, schedules, and other dates.



[3.4] Time Format

With the help of this Dropdown, the user can select their preferred time format.

Possible options:
12 Hour (AM/PM): 02:30 PM
24 Hour: 14:30
The selected format should be used for interview schedules, reminders, reports, and other time-related information.
