Profile  :-


[1] Profile Information


[1.1] Profile Picture
The Profile Picture section allows the user to view and update their profile photo.

Displays the user's current profile picture or initials.
The Camera Icon allows the user to upload or change their profile picture.
The uploaded image should be saved and displayed throughout the application.



[1.2] Full Name
The Full Name field displays the user's registered name.

With the help of the Edit Profile option, the user can update their name.
Displays the user's full name.
The updated name should be reflected throughout the application.
It can also be displayed in the sidebar and profile dropdown.



[1.3] Email Address

The Email Address field displays the email address associated with the user's account.
Shows the registered email address.
Can be editable if account settings allow it.
The email can be used for account communication and notifications.


[1.4] Job Role

The Job Role field allows the user to specify their current or preferred professional role.

For example:
AI/ML Engineer
This information can be used to personalize:
Mock interviews
Interview questions
Skill analysis
Job matching
Performance reports



[1.5] Experience

The Experience field displays the user's professional experience.

For example:
2+ Years
The user can update this information according to their current experience level.




[1.6] Phone Number
The Phone Number field contains the user's registered contact number.

Allows the user to view their phone number.
Can be updated through Edit Profile.
Can be used for account-related communication if enabled.



[1.7] Location
The Location field displays the user's current or preferred professional location.

For example:
Pune, Maharashtra, India
This information can be useful for:

Job recommendations
Location-based opportunities
Profile personalization




[1.8] Bio
The Bio field allows the user to provide a short professional introduction.

For example:
Passionate about building AI solutions and solving real-world problems.
The bio gives recruiters or other authorized users a quick overview of the user's professional interests and background.

[2] Edit Profile :-

[2.1] Edit Profile Button

With the help of the Edit Profile button, the user can modify their personal and professional profile information.

When the user clicks Edit Profile:
Editable fields become active.
The user can update their information.
The user can upload/change their profile picture.
The user can save or cancel the changes.

After clicking Save, the updated information should be stored and displayed across SynaptiRole AI.

[3] Professional Details :-

[3.1] Highest Education

The Highest Education field allows the user to specify their highest educational qualification.

For example:
B.Tech in Artificial Intelligence & Data Science
This information can be used to provide a better understanding of the user's academic background.


[3.2] Institute

The Institute field displays the educational institution from which the user obtained or is pursuing their qualification.
For example:
V.P.K.B.I.E.T, Baramati
The user can update this information through Edit Profile.



[3.3] Skills

The Skills field allows the user to specify their technical and professional skills.
For example:
Python, Machine Learning, Deep Learning, NLP, SQL, React.js, TensorFlow
These skills can be used by SynaptiRole AI for:

Skill matching
Interview question generation
Mock interview customization
Skill performance analysis
Identifying skill gaps



[3.4] Years of Experience
The Years of Experience field displays the user's total professional experience.

For example:
2+ Years
This information can help the system generate interview questions appropriate to the user's experience level.



[3.5] LinkedIn Profile

The LinkedIn Profile field allows the user to add their LinkedIn profile URL.

For example:
https://www.linkedin.com/in/arjun-sharma
The Globe Icon indicates that the link can be opened externally.

The user can use this field to provide their professional networking profile.




[3.6] GitHub Profile
The GitHub Profile field allows the user to add their GitHub profile URL.

For example:
https://github.com/arjunsharma
This can help represent the user's:

Projects
Programming experience
Open-source contributions
Technical skills

[4] Account Details
[4.1] Member Since

The Member Since section displays the date on which the user created their SynaptiRole AI account.
For example:
22 May 2025
This information is primarily used to provide account history information to the user.


[4.2] Account Status
The Account Status section displays the current status of the user's SynaptiRole AI account.
For example:
Active
Possible statuses can include:



Active: Account is currently available and usable.
Suspended: Account access has temporarily been restricted.
Deactivated: Account has been disabled.

The status helps the user understand whether their account is currently operational.
