Resume & Job Description — UI Elements
[1] Upload & Processing Status
[1.1] Upload Documents

Shows whether the Resume and Job Description have been uploaded successfully.

Completed: Both documents are uploaded.
Allows the user to proceed with document processing.
[1.2] Documents Parsed

Shows whether the uploaded documents have been successfully analyzed.

Completed: Documents have been parsed.
Extracted information is used for personalized interviews.
[1.3] Ready for Mock Interviews

Indicates that the Resume and JD are ready for generating personalized mock interviews.

[2] Document Confirmation
[2.1] Upload & Parsing Success Message

Confirms that both documents have been uploaded and parsed successfully.

Resume is ready.
Job Description is ready.
User can proceed to Mock Interviews.
[2.2] Re-upload Documents

Allows the user to replace the existing Resume or Job Description.

Upload updated documents.
New documents are parsed again.
[3] Resume
[3.1] Resume File Information

Displays basic information about the uploaded Resume.

File Name
Upload Date
File Size
Parsing Status
[3.2] Resume Quick Preview

Displays important information extracted from the Resume.

Name
Experience
Current Role
Current Company
[3.3] Preview Resume

Allows the user to open and view the complete uploaded Resume.

[4] Job Description
[4.1] Job Description File Information

Displays basic information about the uploaded Job Description.

File Name
Upload Date
File Size
Parsing Status
[4.2] Job Description Quick Preview

Displays important information extracted from the JD.

Job Title
Experience Required
Employment Type
Key Skills
[4.3] Key Skills from JD

Displays the important skills extracted from the Job Description.

For example:

Python | Machine Learning | Deep Learning | NLP | SQL | TensorFlow

These skills are used to generate role-specific interview questions.

[4.4] Preview JD

Allows the user to open and view the complete Job Description.

[5] Mock Interview Preparation
[5.1] Ready to Start Your Mock Interviews?

Informs the user that their Resume and JD are ready for personalized interviews.

The system can generate:

Resume-based questions
JD-based questions
Technical questions
Experience-based questions
[5.2] Proceed to Mock Interviews

Allows the user to start the Mock Interview process.

When clicked:

Resume and JD data is provided to the interview system.
Personalized questions are prepared.
User is redirected to the Mock Interview interface.
[5.3] Interview Duration

Displays the estimated interview duration.

Example:

Takes ~30–45 mins

[6] Navigation
[6.1] Back to Dashboard

Allows the user to return to the Dashboard without starting the interview.

[6.2] Dashboard

Opens the main SynaptiRole AI Dashboard.

[6.3] Resume & JD

Opens the Resume & Job Description section.

[6.4] Mock Interviews

Opens the AI-powered Mock Interview section.

[6.5] Reports

Allows the user to view:

Interview Scores
Feedback
Performance Analysis
Reports
[6.6] Settings

Allows the user to manage:

Notifications
Privacy
Appearance
Account Settings
[7] User Controls
[7.1] Notification Bell

Displays application notifications such as:

Interview Reminders
Interview Feedback
Performance Updates
System Notifications
[7.2] Profile Menu

Displays the user's:

Profile Picture
Name
Job Role

It provides access to Profile, Account Settings, and Logout.
