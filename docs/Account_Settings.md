

[1] Account Information :-

[1.1] Full Name
The Full Name field allows the user to view and update the name associated with their SynaptiRole AI account.

Displays the user's current name.
The user can modify the name if required.
The updated name should be reflected across the application.



[1.2] Email Address
The Email Address field displays the email address associated with the user's account.

Allows the user to view their registered email.
Can be updated if email-change functionality is supported.
The email is used for account-related communication and notifications.



[1.3] Phone Number
The Phone Number field allows the user to view or update their registered contact number.

Used for account-related communication where applicable.
The user can update the number when required.
Any sensitive changes should require appropriate verification.



[1.4] Job Role
The Job Role dropdown allows the user to select or update their current/professional role.
For example:
AI/ML Engineer

The selected role can be used by SynaptiRole AI to personalize:

Mock interviews
Interview questions
Skill evaluation
Performance analysis




[1.5] Experience
The Experience dropdown allows the user to select their professional experience level.

For example:
2+ Years
This information can help the system generate interview questions appropriate to the user's experience level.



[1.6] Location
The Location field allows the user to view or update their current/professional location.

For example:
Pune, Maharashtra, India

This can be useful for profile personalization and location-based job opportunities.



[1.7] Save Changes
With the help of the Save Changes button, the user can save modifications made to their account information.

When clicked:
The system validates the entered information.
The updated information is saved.
A confirmation message is displayed.
The updated details are reflected throughout the application.

[2] Email Preferences :- 

The Email Preferences section allows the user to control which types of emails they want to receive from SynaptiRole AI.



[2.1] Product Updates
With the help of this Toggle Switch, the user can choose whether they want to receive emails about new features, improvements, and product updates.

ON: User receives product-update emails.
OFF: User does not receive product-update emails.




[2.2] Weekly Performance Summary

With the help of this Toggle Switch, the user can choose whether they want to receive a weekly summary of their interview performance through email.

ON: Weekly performance summary is sent through email.
OFF: Weekly performance summary emails are disabled.

The summary may include:
Overall performance score
Interview performance
Key strengths
Areas for improvement
Skill performance



[2.3] Tips & Recommendations

With the help of this Toggle Switch, the user can choose whether they want to receive personalized interview and career-related tips and recommendations.

ON: User receives relevant tips and recommendations.
OFF: These emails are disabled.

Examples may include:
Interview preparation tips
Skill improvement suggestions
Recommended practice areas
Career-related recommendations




[2.4] Offers & Promotions

With the help of this Toggle Switch, the user can choose whether they want to receive emails about offers, promotions, and special events.

ON: User receives promotional emails.
OFF: Promotional emails are disabled.

[3] Security

The Security section allows the user to manage their password and additional account-security features.

[3.1] Password

The Password section displays the current security status of the user's password.

For example:
Your password is secure
The actual password should never be displayed in plain text.
The masked characters indicate that the password is protected.





[3.2] Update Password

With the help of the Update Password button, the user can change their existing account password.
The password-change process can require:

Current password
New password
Confirm new password
Password validation
Save/confirm action

After successfully changing the password, the user should receive a confirmation.

[4] Sessions :- 


[4.1] Active Sessions

The Sessions section allows the user to manage devices and sessions where their SynaptiRole AI account is currently logged in.

It can provide information such as:

Device
Browser
Operating system
Approximate location
Last active time

This helps the user identify unfamiliar account activity.



[4.2] View All Sessions

With the help of the View All Sessions button, the user can view all active and/or recent account sessions.

From the sessions page, the user can potentially:

View logged-in devices
Identify unfamiliar sessions
Log out from individual devices
Log out from all other devices

[5] Delete Account :- 


[5.1] Delete Account

The Delete Account option allows the user to permanently delete their SynaptiRole AI account.

This is a destructive and irreversible action, so the system should clearly warn the user before proceeding.

Account deletion may remove:

Profile information
Resume information
Interview history
Interview reports
Performance data
Account preferences
Other user-associated data, subject to applicable retention requirements



[5.2] Delete Account Confirmation

When the user clicks Delete Account, the system should display a confirmation dialog before permanently deleting the account.

The confirmation should clearly explain:

What information will be deleted
That the action may be irreversible
Whether any data will be retained for legal/security reasons

The user should then have options such as:

Cancel → Keeps the account.

Confirm Delete → Permanently deletes/deactivates the account according to the application's deletion policy.
